# Carriagetown Detailing — unofficial website concept

A private, speculative one-page concept for **Carriagetown Detailing LLC**, Amesbury, MA.

> **Unofficial.** Created independently for presentation purposes. Not commissioned or
> approved by Carriagetown Detailing LLC. Do not publish it, index it, or present it as
> the business's website. The disclaimer in the footer stays until the owner explicitly
> approves an official launch **and** asset permissions are resolved.

## Run it

```bash
npm install
npm run assets   # fetch the business's photos, then optimise to AVIF/WebP
npm run dev      # http://localhost:4173
npm run qa       # render + inspect at 1440/768/390/360, reduced-motion, no-JS
```

`npm run dev` serves `public/` and sends `X-Robots-Tag: noindex, nofollow, noarchive`.

## Photographs are not in this repository

`npm run assets` downloads them from the business's own site at build time. They are
**not committed** — ownership and releases are unresolved (see
`scripts/assets.manifest.json`).

If the download fails, `fetch-assets` exits non-zero and **never substitutes stock or
generated imagery**. Each image slot then renders a labelled pending-asset panel at the
correct aspect ratio, so layout and motion stay inspectable. The page is not presentable
to the owner in that state.

## Layout

```
public/index.html              one route, six sections

public/assets/js/site.js       menu, reveals, hero entrance, pinned stage
public/assets/fonts/           self-hosted Barlow Condensed + Inter (124 KB)
public/assets/photos/          generated by npm run assets — gitignored
scripts/assets.manifest.json   source + permission manifest for every image
scripts/qa.mjs                 the QA harness
docs/                          QA report, sales handoff, measurement log
qa/screenshots/                rendered evidence
```

## Design notes

- **Direction:** "Every detail, in focus."
- **Palette** (proposed, not the business's official brand): Ink `#101113` ·
  Warm white `#F4F2EC` · Steel `#8A929A` · Signal yellow `#F4D64E`.
- **Type:** Barlow Condensed (display) + Inter (body), self-hosted, two families.
- **Motion:** GSAP + ScrollTrigger for two moments — a hero frame that opens under
  ~900 ms, and a desktop pinned work stage with masked reveals and an 01/02/03 index.
  Both are progressive enhancements. Under `prefers-reduced-motion`, without JS, or
  below 960 px the page is an ordinary, complete, fully readable document. Nothing is
  ever left at `opacity: 0`.

## Content rules this page follows

- **No prices.** The official homepage and /services contradict each other
  (sedan ceramic $900–1,100 vs $850–1,000; sedan interior $150 vs $155). Every path
  leads to "request a quote" instead. Confirm real prices with the owner before launch.
- **Reviews** are shown as `4.9 · 55 reviews` with the qualifier
  "Google reviews shown on existing site · checked Sep 2026" and a link to the exact
  Maps destination. No Google logo. Not described as independently verified.
- **No invented facts** — no founding date, biography, team size, certification, coating
  brand, award, town list or mileage radius. No testimonials, no before/after pairs, no
  AI people, no stock imagery.
- **Photo captions are descriptive only.** No image is claimed to be the result of a
  particular service, and the services section says so on the page.
- **No `LocalBusiness` structured data**, no sitemap, no canonical pointing at the
  business's domain, `robots` set to `noindex, nofollow, noarchive`.
- **Two distinct numbers**, correctly labelled: text `(978) 490-4139`,
  call `(978) 572-6344`.
